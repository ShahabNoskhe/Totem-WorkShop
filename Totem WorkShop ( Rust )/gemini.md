## 📖 ۱. معرفی پروژه

نرم‌افزار **Totem Workshop Pro** یک ابزار تخصصی و کاربردی برای گیمرها، ماد سازان و تولیدکنندگان محتوای بازی **Minecraft** است که فرآیند ساخت ریسورس‌پک‌های سفارشی برای **آیتم توتم (Totem of Undying)** را به ساده‌ترین و سریع‌ترین شکل ممکن درمی‌آورد.

در این نسخه، کل پروژه از زبان Python به زبان **Rust** پورت شده و رابط کاربری آن با استفاده از فریم‌ورک مدرن و سریع **egui / eframe** با حفظ تم تیره و تجربه کاربری بازسازی شده است.

---

## ⚡ ۲. مزایای نسخه پورت شده (Rust vs Python)

| ویژگی | نسخه قبلی (Python / CustomTkinter) | نسخه جدید (Rust / eframe) |
| :--- | :--- | :--- |
| **نیازمندی‌ها** | نیاز به نصب پایتون و ده‌ها پکیج سنگین (OpenCV, rembg, Pillow, etc.) | فایل اجرایی کاملاً مستقل و تک‌فایلی (`.exe`) بدون نیاز به پایتون |
| **سرعت پردازش تصویر** | بر پایه مفسر پایتون و مصرف رم بالا | رندرینگ بسیار سریع با کتابخانه `image` در زبان Rust |
| **مصرف حافظه (RAM)** | معمولاً بالای ۵۰۰ تا ۱۰۰۰ مگابایت در ران‌تایم پایتون | کمتر از ۵۰ الی ۱۰۰ مگابایت |
| **ثبات رابط کاربری (GUI)** | امکان فریز شدن یا تأخیر هنگام پردازش سنگین | استفاده از معماری Multi-threading کامل با Channelها و رابط کاربری همواره روان |
| **مدل‌های سه‌بعدی** | وابسته به کدهای پایتون | تولید اتمیک و سریع فایل‌های JSON مدل ماینکرفت |

## 🏗️ ۳. ساختار و معماری ماژولار پروژه

پروژه به صورت کاملاً ماژولار در پوشه `src` طراحی شده است:

```
Totem WorkShop(Rust)/
├── Cargo.toml                  # تعاریف وابستگی‌ها و بهینه‌سازی‌های پروژه
├── gemini.md                   # مستندات و راهنمای جامع پروژه
├── totem_settings.json         # ذخیره و بازیابی تنظیمات (مسیر پیش‌فرض ذخیره)
├── TotemWorkShop.py            # اسکریپت مرجع اولیه پایتون
└── src/
    ├── main.rs                 # نقطه ورود برنامه، تنظیمات پنجره و اجرای eframe
    ├── app.rs                  # بدنه اصلی نرم‌افزار، تم‌ها و مسیریابی صفحات
    ├── config.rs               # بارگذاری و ذخیره فایل تنظیمات totem_settings.json
    ├── types.rs                # تعاریف داده‌ای، کدهای رنگی ماینکرفت و نسخه‌ها
    ├── core/                   # لایه پردازش و منطق ماینکرفت
    │   ├── mojang_api.rs       # استعلام و دریافت اسکین از سرورهای Mojang و Minotar
    │   ├── skin_processor.rs   # ساخت تکسچر ۲بعدی توتم با الگوریتم دقیق برش و ماسک
    │   ├── model_generator.rs  # تولید مدل‌های ۳بعدی (skin.json و totem_of_undying.json)
    │   ├── video_processor.rs  # استخراج فریم‌های ویدیو و تبدیل صدا از طریق FFmpeg
    │   ├── spritesheet.rs      # ایجاد Spritesheet عمودی و ساخت متادیتای انیمیشن
    │   └── pack_builder.rs     # ساخت سلسله‌مراتب فایل‌ها و pack.mcmeta ریسورس‌پک
    └── ui/                     # لایه رابط کاربری گرافیکی (GUI)
        ├── dashboard.rs        # صفحه اصلی داشبورد با کارت‌های شیشه‌ای
        ├── animated_totem.rs   # ماژول و پنل ساخت توتم انیمیشنی از ویدیو
        ├── skin_forge.rs       # ماژول ساخت توتم از روی اسکین با پیش‌نمایش زنده
        └── widgets.rs          # المان‌های کمکی مانند پالت رنگ‌های ماینکرفت
```

## 🛠️ ۴. پیش‌نیازها و ابزارها

1. **کامپایلر Rust**: نسخه 1.80 یا بالاتر (با دستور `rustc --version` و `cargo --version` بررسی کنید).
2. **FFmpeg**: برای تبدیل فرمت‌های ویدیو به فریم‌های PNG و تبدیل فایل‌های صوتی به `use.ogg` فرمت ماینکرفت به ابزار `ffmpeg` نیاز است که روی سیستم کاربر موجود بوده و در متغیر PATH قرار دارد.

## 🎮 ۶. قابلیت‌ها و ماژول‌های نرم‌افزار

### ۱. ماژول Animated Totem (ساخت توتم متحرک)
- **پشتیبانی از انواع فرمت‌های ویدیویی:** `mp4`, `avi`, `mov`, `mkv`, `webm`
- **تنظیمات فریم:** انتخاب فریم‌های آماده (۵، ۱۵، ۳۵، ۷۵) یا مقدار عددی دلخواه
- **کنترل پرش فریم (Frame Skip):** برای متراکم کردن حرکات و جلوگیری از سنگین شدن ریسورس‌پک
- **حذف هوشمند پس‌زمینه (Chroma Key & Edge Clear):** شفاف‌سازی پس‌زمینه‌های یکنواخت به صورت خودکار
- **ابعاد کانواس:** قابلیت تنظیم روی ۶۴ (سبک)، ۱۲۸ (استاندارد)، ۲۵۶ (با کیفیت بالا)
- **ساخت خودکار Spritesheet:** اتصال عمودی تمام فریم‌ها و نوشتن `totem_of_undying.png.mcmeta` با قابلیت `interpolate: true`

### ۲. ماژول Skin-Forge (توتم ۲بعدی و ۳بعدی از اسکین)
- **دریافت خودکار از نام‌کاربری:** دانلود مستقیم اسکین با اتصال به سرورهای رسمی Mojang / Minotar
- **آپلود فایل محلی:** انتخاب مستقیم فایل `png` اسکین (پشتیبانی از اسکین‌های ۶۴×۶۴ و ۶۴×۳۲)
- **پیش‌نمایش زنده (Hand Preview):** نمایش آنی توتم در حالت ۲بعدی و مدل ایستاده ۳بعدی
- **حالت ۲بعدی (2D Mode):** برش دقیق لایه‌های سر، دست‌ها، تنه، اعمال لایه‌های تزئینی بیرونی (Overlay) و حذف پیکسل‌های اضافه بر اساس فرمت استاندارد توتم ماینکرفت
- **حالت ۳بعدی (3D Mode):** رندر مدل چندوجهی سفارشی با زوایای دقیق قرارگیری در دست راست، دست چپ، زاویه دید اول شخص و نمای GUI درون اینونتوری

### ۳. ویژگی‌های مشترک
- **پالت رنگ‌های رسمی ماینکرفت:** درج سریع کدهای فرمت رنگی (`§4`, `§c`, `§a`, `§e`, `§l`, ...) در نام و توضیحات پک
- **آیکون سفارشی پک:** تغییر اندازه خودکار هر تصویر به ابعاد ۶۴×۶۴ پیکسل و ذخیره در `pack.png`
- **صدای اختصاصی Pop:** تبدیل و ذخیره مستقیم صداهای `mp3`, `wav`, `ogg` در مسیر `assets/minecraft/sounds/item/totem/use.ogg` همراه با `sounds.json`
- **سازگاری با تمامی نسخه‌ها:** تنظیم خودکار مقدار `pack_format` از نسخه 1.12 تا 1.21+ و ماینکرفت 26
- **ذخیره خودکار مسیر:** به خاطر سپردن پوشه مقصد انتخاب‌شده (سازگار با PrismLauncher یا دایرکتوری رسمی `.minecraft`) در [totem_settings.json](file:///c:/AGY%20Projects/Totem%20WorkShop(Rust)/totem_settings.json)

## 🌐 ۸. نسخه وب و وب‌اسمبلی (WebAssembly / Wasm Edition)

پروژه به طور کامل با معماری **Dual-Target** سازگار شده است؛ یعنی هم به صورت برنامه دسکتاپ بومی ویندوز (`.exe`) و هم به صورت وب‌اپلیکیشن مستقل مبتنی بر **WebAssembly (Wasm)** کامپایل و اجرا می‌شود.

### ۱. ویژگی‌های نسخه وب:
- **اجرای ۱۰۰٪ کلاینت‌ساید (بدون نیاز به سرور یا دیتابیس):** تمام پردازش‌های تصویر، برش لایه‌های اسکین، تولید فایل‌های JSON و فشرده‌سازی ZIP درون مرورگر کاربر انجام می‌شود.
- **دانلود مستقیم پکیج ریسورس‌پک:** در نسخه مرورگر، ریسورس‌پک مستقیماً در قالب یک فایل استاندارد `.zip` توسط مرورگر دانلود می‌شود.
- **پشتیبانی از Drag & Drop اسکین:** امکان کشیدن و رها کردن مستقیم هر فایل PNG اسکین به داخل تب مرورگر.
- **دریافت خودکار اسکین با نام‌کاربری:** با استفاده از سرورهای Minotar و هدرهای باز CORS، اسکین هر بازیکن ماینکرفت بلافاصله در مرورگر دریافت و رندر می‌شود.

### ۲. نحوه کامپایل برای وب با Trunk:
```powershell
.\trunk.exe build --release
```
تمام خروجی نهایی به صورت خودکار در پوشه `dist/` قرار می‌گیرد:
```
dist/
├── index.html                           # سند ریشه با استایل‌های مدرن و لودینگ نرم‌افزار
├── totem_workshop-[hash].js             # بایندر لودینگ جاوااسکریپت
└── totem_workshop-[hash]_bg.wasm        # موتور پردازش کامپایل‌شده Wasm
```

### ۳. نحوه آپلود روی هاست:
کافیست تمام محتویات پوشه `dist/` را درون پوشه `public_html` یا مسیر سایت خود در هر هاستی قرار دهید (سازگار با **GitHub Pages**، **Cloudflare Pages**، **Vercel**، **cPanel**، **Nginx** و **Apache**). به هیچ زبان سمت سروری (مثل PHP یا پایتون یا Node.js) نیاز نیست!

### ۴. تست و اجرای محلی نسخه وب:
```powershell
python -m http.server 8080 --directory dist
# یا مستقیماً با ترانک:
# .\trunk.exe serve --release
```
سپس آدرس `http://localhost:8080` را در مرورگر باز کنید.
